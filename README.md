Weather App

Welcome to the Weather App! This project provides real-time weather updates. It fetches data from OpenWeatherMap and displays it in a user-friendly interface.

Features

Search for weather conditions by city name
Display temperature, humidity, and wind speed
Multiple weather results displayed in a row for better readability


Technologies Used

Django (Backend framework)
OpenWeatherMap API (Weather data source)
jQuery & AJAX (For dynamic updates)
Uses sessions to store weather data 
HTML, CSS, JavaScript (Frontend technologies)
